# mp言語 compiler
mp言語用のコンパイラーです  

## 概要
ダウンロードされる実行ファイルの大きさは100MBに満たないくらいのサイズです  
コンパイラーの対応するのはWindows（32bit、64bit、ARM64版）のみです  
原則、Windows10以降での使用を想定しています  
出力ファイルはWindowsの64bit実行ファイルです  
これはすべての64bitアプリを実行できるWindowsで使用可能です

## 注意
コードファイルのエンコードは指定されない場合、UTF-8として受け入れられます
最適化はデフォルトでオンになっています

## 使い方
mpcom.exeをコーンソール上で起動します  
その際の引数は以下です（「（）」で囲まれる引数は任意で、複数指定はスペースで区切ってください）   
#### version  
内部で使用しているシステムのバージョンの関係で意図されるバージョンではない場合があります
   
#### help  
  
#### （-no） （｛エンコード名｝） （｛出力形式｝） ｛コードファイルのパス｝ （｛中間出力ディレクトリ｝） ｛出力ファイルのパス｝     
この場合は出力ファイルが予定されるディレクトリに中間出力（一時ファイル）が生成されます 
「-no」は最適化を無効化します
｛エンコード名｝は  
-「utf8」（UTF-8｜デフォルト値）  
-「utf16」  
-「utf32」  
-「ascii」  
-「utf16_l」（リトルエンディアンUTF-16）  
-「utf16_b」（ビッグエンディアンUTF-16）  
｛出力形式｝は  
-「html」（ウェブサイト｜デフォルト値）  
-「exe」（Windows 64bit 実行ファイル｜*1）  
*1：Windows向けのコンパイラーでのみ使用可能
